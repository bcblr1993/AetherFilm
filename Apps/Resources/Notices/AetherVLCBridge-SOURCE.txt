Changes include a separate player/delegate/notification namespace, typed
stopping snapshots and clock/input callbacks, checked clock interpolation,
and package-relative header imports. The fixed libVLC core is unchanged.

The package includes 23 hashed original inputs, the exact patch, two generators
and provenance. Its 22 generated source files reproduce the compiled package
bytes. The complete application and bridge source at the same final commit,
the project specification, dependency locks, original source materials, notices
and rebuilding/relinking tools must accompany the distributed release. Earlier
VLCKit source-input archives alone do not contain the later derived bridge or
the final application and must not substitute for that complete same-source
asset. See the repository release assets and the package README/provenance:
https://github.com/bcblr1993/AetherFilm

Five platform/architecture consumers have compiled and strongly linked the
typed wrapper callbacks with unchanged implementation bytes and an explicitly
recorded local dependency-manifest override. These checks do not establish an
independent full libVLC engine rebuild, modified-library App Store distribution,
notarized GUI playback, physical-device playback or audible-output acceptance.
Final application relinking evidence and remaining gates are recorded with the
release source commit; no release has been published while acceptance is open.
