# v0.1.0 兼容性与验证范围

最低系统为 macOS 26、iOS / iPadOS 26。此表随真实验收更新；当前尚未发布版本。文件扩展名可被浏览器识别，不等于扩展名下所有编码组合都已验证。

| 样片组合 | iOS 26.5 Simulator | macOS 27 VM | iPhone |
| --- | --- | --- | --- |
| MP4 · H.264 / AAC | 画面、音频输出与时间推进通过 | 待图形登录后验收 | 待解锁验收 |
| MOV · HEVC / AAC | 画面、音频输出与时间推进通过 | 待验收 | 待验收 |
| AVI · MPEG-4 / MP3 | 画面、音频输出与时间推进通过 | 待验收 | 待验收 |
| MKV · H.264 / 双 AAC 音轨 / 内嵌 SRT、ASS / 章节 | 输出、轨道切换和章节通过 | 待验收 | 待验收 |
| 外挂 SRT / ASS / WebVTT | 真实轨道加载与选中通过 | 待验收 | 待验收 |
| SMB2 → HTTP Range → H.264 / AAC | 输出、逐次远近 seek、停止后重开通过 | 待验收 | 待网络 / 真机验收 |
| 3840×2160 HEVC / AAC | 显示帧、音频输出与时间推进通过；软件解码 | 待验收 | 待硬件解码验收 |

播放输出检查分别读取解码帧、显示帧、解码音频与已输出音频缓冲计数。截图、字幕字形 / ASS 样式、实际声音、同步和真机性能仍须独立验收；模拟器结果不替代这些证据。测试片源由本仓库脚本合成，未使用用户影片。

NAS 支持 SMB2 和库所支持的 SMB3 协商。可选「要求 SMB 3 加密」在不支持的服务上明确失败，不退回明文；当前实际验收已证明拒绝路径，加密成功与不同厂商 NAS 兼容性仍待验证。

首版不宣称完整 Infuse 格式覆盖、ISO / BDMV 菜单、HDR / Dolby Vision / Atmos、画中画、投屏或在线字幕服务。其他可识别的容器与编码组合以实际播放结果为准。完整命令、结果包、失败和分发状态见 [TEST_MATRIX.md](TEST_MATRIX.md)。
