# AetherFilm v0.1.0 产品规划

状态：一期范围已确认。用户选择 **1、2、3、4、5、9**，主要使用 **SMB NAS**；名称 AetherFilm，公开 GitHub 仓库，macOS 下载包先发布，iOS 同步开发、构建与测试。用户追加要求：UI 体验必须好，设计漂亮的原创 App 图标。

## 产品定位

轻量的私人视频播放器。打开应用后，添加自己的影片，快速找到内容，然后继续观看。借鉴 Infuse 的核心使用流程，不复制其品牌、素材或完整功能树。

最低系统：macOS 26.0、iOS / iPadOS 26.0。macOS 首版仅支持 Apple Silicon（arm64），按用户 2026-10-04 的确认取消 Intel Mac 兼容与发布验收。以 Xcode 27 和系统 SwiftUI 控件实现原生玻璃设计，避免为了外观提高最低版本。

## 界面结构

- macOS：系统侧栏包含「本地文件」「继续观看」和 SMB 片源；导入与连接 NAS 放在工具栏。播放器单独展示，支持快捷键。
- iPhone：简洁导航，片源切换与文件 / 目录浏览；继续观看保留直接续播入口；播放时呈现适合触控的控制栏。
- iPad：自适应侧栏；横竖屏均可用。
- 视频内容与文件名保持清晰，原生 Liquid Glass 用于导航、工具栏、浮动播放控制。跟随系统动态字体、深浅色和减少透明度。
- 设置仅保留日常必要项；解码器和协议内部细节不进入主流程。

## 后续功能

2026-10-06 用户授权推进稳定性收尾和 NAS 日常观看优化：保存每个片源最后成功打开的目录与最后打开的视频行；提供常用目录及共享根目录入口；在播放设置中增加持久化的自动连播开关，并展示按当前列表文件名顺序选出的下一条。常用目录是片源内的路径快捷入口，不引入影片收藏、海报系统或剧集识别。旧版观看记录须直接兼容，原文件和 Keychain 凭据保持既有安全边界。

WebDAV / NFS / FTP / SFTP、Jellyfin / Emby / Plex、自动海报刮削和影片库、第三方网盘 OAuth、OpenSubtitles、Trakt、iCloud 跨设备同步、离线下载队列、画中画 / 投屏、自动跳片头、ISO / BDMV 片源、完整收藏 / 播放列表体系、上传和高级文件管理、家长控制。

Apple TV / Vision Pro 不在当前双端目标内。ISO / BDMV 文件播放与交互式蓝光菜单须区分，不能由片源格式支持推导菜单能力。

HDR / Dolby Vision / Atmos 等能力按系统、解码后端和设备实际结果发布支持表，首版不以 Infuse 的全格式宣称代替验证。

## 发布完成定义

1. GitHub 公共仓库与架构、贡献说明、隐私说明、CI 和版本脚本可用。
2. 首版全部功能矩阵通过，失败和未测项明确保留；不以模拟服务测试替代真机播放。
3. macOS 包完成 Developer ID 签名、公证、安装与下载验证。
4. iOS archive 和模拟器测试通过；真机安装与播放验收通过。用户接受 macOS 下载包先发布、iOS 同步构建测试；TestFlight / App Store 分发按开发者账号条件推进，并明确披露状态。不能把模拟器包称作 iPhone 安装包，也不能将 iOS 公开上线追加为本次 macOS 发布的必需条件。
5. GitHub Release 带源码版本、macOS 下载、校验值、说明和 iOS 分发状态；官网采用现有中英双语产品 / 版本记录结构，并验证部署。
