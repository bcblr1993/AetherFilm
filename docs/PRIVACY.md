# AetherFilm 隐私说明（v0.1.0）

AetherFilm 播放你选择的本地视频和 SMB NAS 文件。

- NAS 密码保存在系统钥匙串；用户名和域也存在本机片源配置中。片源配置与观看记录只保存在本机。
- 浏览与播放直接访问你配置的 NAS。播放器通过仅监听本机回环地址的随机 URL 读取视频；URL 不包含 NAS 密码。
- 首版没有 AetherFilm 账号、广告、行为统计、自动元数据上传或云同步。
- 导入本地文件时，Mac 保留安全访问授权；iOS 将所选文件复制到应用目录。
- 「从列表移除」不删除原始影片；移除 NAS 片源不删除 NAS 文件。
- 网站和 GitHub 反馈链接只有在你主动打开时访问对应服务。提交问题前请去除服务器私密地址、凭据和个人影片信息。

本说明对应确定的一期范围。后续新增网络服务或同步功能时，会在发布前更新说明。
